ต้องเข้าสู่ระบบ Claude ก่อนใช้งาน

ระบบนี้ใช้ Claude ในบัญชีของผู้ใช้แต่ละคนอ่านเอกสาร การอ่านเอกสารจึงใช้โควตาของบัญชีที่เข้าสู่ระบบ ไม่มีการใช้ API key หรือบัญชีกลาง

  1. เข้าสู่ระบบ claude.ai ด้วยบัญชีของคุณ (ถ้ายังไม่มีบัญชี สมัครได้ที่หน้าเดียวกัน)
  2. กดปุ่ม "เปิดระบบใน Claude" ด้านล่าง
  3. ครั้งแรกที่กดอ่านเอกสาร ระบบจะขออนุญาตใช้ Claude ให้กด "อนุญาต"
เปิดระบบใน Claude เข้าสู่ระบบ claude.ai

ถ้าเปิดแล้วเห็นข้อความ "กรุณาเข้าสู่ระบบ Claude ก่อนใช้งาน" แปลว่ายังไม่ได้เข้าสู่ระบบในเบราว์เซอร์นั้น ให้เข้าสู่ระบบแล้วเปิดลิงก์อีกครั้ง
