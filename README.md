# ระบบจัดหน้าบันทึกข้อความ

แปลง PDF บันทึกข้อความลงแม่แบบกลางเป็นไฟล์ Word ที่แก้ต่อได้ และแปลงไฟล์ Word เป็น PDF

**เปิดใช้งาน:** https://claude.ai/artifact/2sPzwD9QCAP85tgk1LUYfN

## ต้องเข้าสู่ระบบ Claude ก่อนใช้งาน

ระบบทำงานอยู่บน Claude และใช้ Claude ในบัญชีของผู้ใช้แต่ละคนอ่านเอกสาร การอ่านจึงใช้โควตาของบัญชีที่เข้าสู่ระบบ ไม่มีการใช้ API key หรือบัญชีกลาง

1. เข้าสู่ระบบ https://claude.ai ด้วยบัญชีของคุณ
2. เปิดลิงก์ด้านบน
3. ครั้งแรกที่กดอ่านเอกสาร ระบบจะขออนุญาตใช้ Claude ให้กด "อนุญาต"

ถ้ายังไม่ได้เข้าสู่ระบบ หน้าระบบจะแสดงเพียงข้อความ "กรุณาเข้าสู่ระบบ Claude ก่อนใช้งาน" และยังไม่เปิดเครื่องมือให้ใช้

## ใช้ทำอะไรได้

**PDF → Word:** แนบ PDF → Claude อ่านจากภาพหน้ากระดาษแล้วพิมพ์ใหม่ลงช่อง ส่วนงาน / โทร. / ที่ / วันที่ / เรื่อง / เรียน / เนื้อความ / ผู้ลงนาม → ตรวจแก้ → ดาวน์โหลด .docx หรือ PDF

**Word → PDF:** แนบ .docx → ระบบจัดหน้าตามขนาดกระดาษ ระยะขอบ และเลขหน้าของไฟล์ → ดาวน์โหลด PDF

## แม่แบบกลาง (ล็อคค่า)

| รายการ | ค่า |
|---|---|
| กระดาษ | A4 แนวตั้ง |
| กั้นบน / ล่าง | 1.25 / 0.50 ซม. |
| กั้นซ้าย / ขวา | 2.54 / 2.54 ซม. |
| ฟอนต์ | TH SarabunPSK 16 pt, ชื่อหนังสือ TH Sarabun New 24 pt ตัวหนา |
| ระยะบรรทัด | 1 เท่า, ก่อน/หลังย่อหน้า 0 |
| ย่อหน้า | บรรทัดแรก 1.27 ซม. จัดแบบกระจายไทย |
| แท็บ ที่ / เรื่อง / เรียน | 1.27 ซม. |
| คอลัมน์ โทร. / วันที่ | 9.00 ซม. |
| เลขหน้า | "- n -" กลางหัวกระดาษ เริ่มหน้า 2 |

ไฟล์แม่แบบอยู่ในโฟลเดอร์ `template/` ใช้ใน Word ได้โดยตรง (`memo-template.dotx` ดับเบิลคลิกแล้วได้เอกสารใหม่ทุกครั้ง) ส่วนหัวถูกล็อคไว้ พิมพ์ได้เฉพาะช่องกรอก ปลดล็อคได้ที่ Review → Restrict Editing → Stop Protection (ไม่มีรหัสผ่าน)

## เปิดหน้านี้ด้วย GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save จะได้หน้า `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ที่มีปุ่มพาไปเปิดระบบใน Claude

## ข้อจำกัด

- PDF ที่ได้จาก Word → PDF เป็นภาพหน้ากระดาษ พิมพ์และแนบส่งได้ แต่เลือกคัดลอกข้อความไม่ได้
- รองรับ .docx เท่านั้น (.doc แบบเก่าให้บันทึกเป็น .docx ก่อน)
- ย่อหน้าแบบกระจายไทยแสดงเป็นชิดซ้ายในตัวอย่างและใน PDF ไฟล์ Word ที่ดาวน์โหลดไม่ได้รับผลกระทบ
